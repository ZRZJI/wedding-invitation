## 📋 逐页配置说明

### 第一页：封面

- **上传** `01-hero.png` → 设宽375px，自动等比例
- **背景**：不需要单独设背景，图片自带红色渐变
- **可叠加元素**：如果需要，可以在图片上加一个"向下滑动"箭头图标

### 第二页：邀请语

- **上传** `02-invitation.png` → 设宽375px
- **背景色**：`#FAF8F4`（米白），与图片无缝衔接

### 第三页：婚纱照展示

这是唯一需要手动排版的部分：

- **背景色**：`#FAF8F4`
- **标题**：用平台文字工具，输入"我们的故事"，字号22px，字间距6px，颜色`#3D1C0A`
- **副标题**：输入"Our Story"，字号11px，颜色`#B8A898`

**照片排版规则（杂志风格集群）**：

分3组集群 + 1张收尾，共9张照片：

```
集群1：一大左 + 二小右
┌──────────┬────┐
│  照片1   │ 照2│
│ (52%)   ├────┤
│          │ 照3│
└──────────┴────┘
文字分隔："初见时的心动，是往后余生的序章"

集群2：一大右 + 二小左
┌────┬──────────┐
│ 照4│  照片5   │
├────┤ (52%)   │
│ 照6│          │
└────┴──────────┘
文字分隔："执子之手，与子偕老"

集群3：二图并排
┌─────────┬──────┐
│ 照片7   │照片8 │
│ (52%)  │(44%) │
└─────────┴──────┘
文字分隔："往后余生，目光所至，皆是你"

收尾：照片9居中（宽78%）
```

- **每个集群间距**：36px
- **集群内图片间距**：8px
- **文字分隔**：Georgie斜体，字号13px，颜色`#B0A090`，上下各一条28px金色细线

> 💡 如果平台支持**自定义HTML组件/区块**，建议直接用原始HTML代码嵌入，排版最精准。代码见下方"附录：婚纱照HTML"。

### 第四页：时间 & 地点

- **背景色**：`#6B0F1A` → `#C41E3A` 渐变（或直接用深红纯色）
- **上传** `03-time-card.png` → 设宽327px，居中
- **上传** `04-location-card.png` → 设宽327px，居中
- 两张卡片上下间距：20px

### 第五页：确认出席（问卷）

- **背景色**：`#FAF8F4`
- **上传** `05-rsvp-header.png` → 设宽375px
- **下方插入**：**iframe组件**（嵌入腾讯问卷）

**腾讯问卷嵌入配置**：
- 在腾讯问卷后台 → 发布 → 获取嵌入代码
- 在H5平台添加"自定义HTML"或"网页组件"
- 粘贴iframe代码，宽度100%，高度建议600px
- ⚠️ 如果腾讯问卷有 X-Frame-Options 限制导致不显示，换用**金数据（jinshuju.net）** 或**腾讯文档收集表**，这两个默认支持iframe嵌入

### 第六页：底部

- **背景色**：`#4A1018`（深红棕）
- **上传** `06-footer.png` → 设宽375px

## ⚡ 快速替代方案

如果觉得手动排版9张照片太麻烦，可以在H5平台使用**图片轮播组件**：
1. 上传9张婚纱照
2. 添加图片轮播/画廊组件
3. 设置左右滑动切换
4. 这样手机上长辈直接左右滑就能看
